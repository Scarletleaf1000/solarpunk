# Solarpunk
*A Tech Mod*

Solarpunk is a minecraft tech mod that allows you to power machines with the sun.
However it doesn't just add solar panels, it also adds the ability to collect power directly from the sun itself.

Solarpunk is currently in early development and is not yet ready for release.
Many features have yet to be added.

Join the [Discord](https://discord.gg/NrMwNE72qZ) to chat with the community and talk about the mod.
